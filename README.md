# ⚡ AI-Powered Energy Consumption Forecasting Dashboard

## 🚀 Overview
This project is an AI-powered energy forecasting system that predicts future electricity consumption using LSTM (Long Short-Term Memory) neural networks.

It includes an interactive dashboard built with Streamlit to visualize predictions and simulate real-world smart energy systems.

---

## 🎯 Problem Statement
Unpredictable energy demand leads to:
- Power wastage ⚡
- High electricity costs 💸
- Inefficient grid management 🌍

---

## 💡 Solution
This system:
- Forecasts energy consumption using AI
- Helps optimize usage and reduce waste
- Simulates real-world smart grid analytics

---

## 🛠️ Tech Stack
- Python
- TensorFlow (LSTM)
- Streamlit
- Pandas, NumPy
- Plotly

---

## 📊 Features
- 📈 Time-series forecasting using LSTM
- 📊 Interactive dashboard UI
- ⚡ Real-time prediction visualization
- 📉 RMSE evaluation metric
- 📂 Upload your own dataset

---

## 🧠 Model
- LSTM Neural Network
- Sequence-based time-series learning
- Predicts future energy usage from historical data
